# 디자인 시스템 규칙서 (Claude Design 등록용)

> 실습③ 에서 **Claude 디자인 시스템**을 만들 때
> `Company name and blurb` / `Notes` 칸과 첨부 파일로 사용하는 규칙서입니다.

---

## 1. 시스템 이름 / 소개문 (Company name and blurb 칸에 붙여넣기)

```
삼성중공업 업무보고 디자인 시스템 —
공정·품질·안전·구매·설계변경 등 조선소 업무 보고를 위한
16:9 PPT와 단일 파일 HTML 보고서를 같은 규칙으로 생산하는 시스템.
경영층 보고에 쓰이므로 신뢰감·가독성·정확성을 장식보다 우선한다.
```

---

## 2. 고정 규칙 (Notes 칸에 붙여넣기)

```
모든 산출물은 삼성중공업 업무 보고 스타일을 따른다.
헤더는 진한 남색 #0B1F3A로 고정하고 높이는 슬라이드 높이의 12%로 한다.
헤더 좌측에 보고구분 또는 프로젝트명, 중앙에 결론이 드러나는 액션 타이틀,
우측에 기준일 캡슐을 배치한다.
본문은 밝은 배경, 넓은 여백, 카드형 요약, KPI 카드, 표, 이슈 카드,
단계형 프로세스, 비교 박스, 체크리스트 중심으로 구성한다.
색은 아래 토큰만 사용한다.
  남색 #0B1F3A / 파랑 #1428A0 / 하늘 #4A7FD4 /
  배경 #FFFFFF / 섹션배경 #F4F6FA / 글자 #16233F / 보조글자 #6B7793 /
  선 #DFE4EE / 정상 #1B7F4B / 주의 #B8860B / 위험 #B3261E
본문 글자는 15px 이상, 캡션은 13px 이상으로 하고 12px 미만은 금지한다.
숫자는 tabular-nums로 정렬하고 표의 숫자 열은 우측 정렬한다.
슬라이드 제목은 명사구가 아니라 결론 문장으로 쓴다.
수치, 일정, 담당자, 결정사항은 근거가 있을 때만 확정 표현을 쓰고
불확실한 항목은 [확인 필요]로 표시한다.
작은 글씨, 과도한 장식, 임의 로고 생성, 근거 없는 수치 생성,
업무와 무관한 예시는 금지한다.
산출물 요청이 PPT면 16:9 슬라이드로, HTML이면 외부 링크 없는
단일 파일 문서로 만들되 두 형식의 수치와 결론 문장은 동일해야 한다.
```

## 3. 첨부할 CSS 토큰 파일 (tokens.css)

```css
:root{
  /* color */
  --navy:#0B1F3A;
  --blue:#1428A0;
  --sky:#4A7FD4;
  --bg:#FFFFFF;
  --section:#F4F6FA;
  --ink:#16233F;
  --muted:#6B7793;
  --line:#DFE4EE;
  --ok:#1B7F4B;
  --warn:#B8860B;
  --bad:#B3261E;

  /* spacing (8px grid) */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px;
  --s5:24px; --s6:32px; --s7:48px; --s8:64px;

  /* radius */
  --r-sm:4px; --r-md:8px; --r-lg:14px;

  /* type */
  --f-display:52px; --f-h1:30px; --f-h2:21px;
  --f-body:15px; --f-caption:13px; --f-kpi:40px;
  --lh-tight:1.15; --lh-body:1.65;
}
.card{background:var(--bg);border:1px solid var(--line);border-radius:var(--r-md);padding:var(--s5)}
.kpi{border-left:3px solid var(--blue);padding-left:var(--s4)}
.kpi b{font-size:var(--f-kpi);font-weight:800;font-variant-numeric:tabular-nums}
table{border-collapse:collapse;width:100%}
th{background:var(--section);color:var(--ink);font-weight:700;padding:10px;text-align:left}
td{border-bottom:1px solid var(--line);padding:10px}
td.num{text-align:right;font-variant-numeric:tabular-nums}
.badge-ok{color:var(--ok)} .badge-warn{color:var(--warn)} .badge-bad{color:var(--bad)}
```

## 4. 등록 절차 요약

| 단계 | 칸 | 넣을 것 | 필수 |
|---|---|---|---|
| 1 | Company name and blurb | 위 1번 소개문 | 필수 |
| 2 | Link code from GitHub | 사내 리포지토리 없으면 비움 | 선택 |
| 3 | Link code from your computer | `tokens.css`가 든 폴더 | 권장 |
| 4 | Upload a .fig file | Figma 시안 있으면 | 선택 |
| 5 | Add fonts, logos and assets | **승인된 로고**, 라인 아이콘, 좋았던 보고서 캡처 | 권장 |
| 6 | Any other notes | 위 2번 고정 규칙 | 필수 |

→ `Continue to generation` → `Generate` (약 5~10분, 탭 열어둘 것)

---

## 5. 로고 관련 절대 규칙

- 회사 로고는 **내부에서 사용 승인된 원본 파일만** 업로드한다.
- 로고가 없다고 AI에게 **만들게 하지 않는다.**
- 폰트도 라이선스가 확인된 것만 쓴다.

## 6. 생성 후 수정하는 두 가지 방법

| 방법 | 언제 | 예시 |
|---|---|---|
| Edit (직접 편집) | 정확한 값을 바꿀 때 | 헤더 높이 120px → 110px |
