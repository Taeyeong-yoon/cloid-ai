# PROMPT — 보고서 PPT 만들기 (붙여넣기용)

> 아래 프롬프트를 **그대로 복사**해서 클로드 대화창에 붙여넣고,
> `DESIGN.md`와 `스토리보드.md` 두 파일을 함께 첨부하세요.

---

## A. 기본형 — 한 번에 PPT 만들기

```
첨부한 두 파일로 보고용 PPT를 만들어줘.

[디자인]
- DESIGN.md의 색·타이포·간격·컴포넌트 규칙을 그대로 지킬 것
- DESIGN.md에 없는 색은 쓰지 말 것

[내용]
- 스토리보드.md의 내용만 사용할 것
- 없는 숫자를 만들어내지 말 것. 불확실하면 [확인 필요]로 표기할 것

[형식]
- 16:9, 8~10장
- 1장: 표지 (보고구분·프로젝트·기준일·작성부서)
- 2장: Executive Summary — 결론 3줄 + KPI 카드 4개
- 3~7장: 본문 (표·차트·이슈 카드)
- 8장: 조치계획 (담당·기한 포함 표)
- 9장: 데이터 출처 및 확인 필요 항목

[슬라이드 제목 규칙]
- 제목은 명사가 아니라 **결론 문장**으로 쓸 것
  (나쁜 예) 공정 현황
  (좋은 예) 진척률 86.4% — 계획 대비 1.6%p 지연

[금지]
- 12px 미만 글씨
- 근거 없는 수치·날짜·담당자 생성
- 임의의 회사 로고 생성
- 한 장에 메시지 2개 이상
```

---

## B. 파일로 저장까지 요청할 때

```
위 내용을 .pptx 파일로 저장해서 다운로드할 수 있게 해줘.
표와 차트는 이미지가 아니라 편집 가능한 개체로 만들어줘.
```

---

## C. 수정 요청 3종 (자주 쓰는 표현)

```
1) 3장 표가 너무 빽빽해. 행을 6개로 줄이고 나머지는 부록으로 빼줘.
2) 전체 톤이 밝아. DESIGN.md의 Primary Navy를 헤더에 더 강하게 적용해줘.
3) 2장 KPI 카드 4개 중 '재해율'은 이번 보고와 무관해. 'FPY'로 바꿔줘.
```

---

## D. 검증 프롬프트 (배포 전 필수)

```
방금 만든 PPT의 모든 숫자를 스토리보드.md 원문과 대조해서
① 원문에 없는 숫자 ② 원문과 다른 숫자 ③ 단위가 틀린 숫자
를 표로 정리해줘. 하나도 없으면 "불일치 없음"이라고만 답해줘.
```

---

## E. 체크리스트

- [ ] 표지에 보고구분·기준일·작성부서가 있는가
- [ ] Executive Summary가 **결론**으로 시작하는가
- [ ] 모든 슬라이드 제목이 결론 문장인가
- [ ] 숫자가 원문과 100% 일치하는가
- [ ] [확인 필요] 항목이 명시되어 있는가
- [ ] 담당·기한이 있는 조치계획 장이 있는가
- [ ] 12px 미만 글씨가 없는가
- [ ] 로고는 승인된 파일만 썼는가
