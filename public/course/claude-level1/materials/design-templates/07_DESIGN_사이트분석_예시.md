## 0. 분석 요약 — 이 사이트의 인상

> **깊은 남색 + 넓은 여백 + 굵은 산세리프.** 신뢰감과 규모감을 주는
> 산업재 기업의 전형적인 톤. 장식보다 정보 밀도와 정렬을 우선한다.

---

## 1. Color

| 역할 | HEX | 근거 (사이트에서 관찰된 위치) |
|---|---|---|
| Primary Navy | `#0B1F3A` | 상단 GNB 배경, 푸터 |
| Primary Blue | `#1428A0` | 주요 버튼, 링크 hover |
| Sky | `#4A7FD4` | 그래프, 보조 강조 |
| Background | `#FFFFFF` | 본문 |
| Section BG | `#F4F6FA` | 섹션 교차 배경 |
| Ink | `#16233F` | 본문 글자 |
| Muted | `#6B7793` | 캡션, 날짜 |
| Line | `#DFE4EE` | 카드 테두리 |

**관찰 규칙**
- 남색과 파랑 2색만으로 위계를 만든다. 3번째 색은 데이터 시각화에서만 등장.
- 섹션이 바뀔 때 흰색 ↔ 연회색 배경을 번갈아 쓴다.

---

## 2. Typography

| 역할 | 크기 | 굵기 | 비고 |
|---|---|---|---|
| Hero | 48–56 px | 700 | 자간 좁게(-1px) |
| Section Title | 32 px | 700 | 위에 짧은 영문 eyebrow |
| Card Title | 18 px | 600 | |
| Body | 15–16 px | 400 | 행간 1.7 (여유 있게) |
| Caption | 13 px | 500 | 색 `--muted` |

- 제목 위에 **영문 소문자 eyebrow**(예: `BUSINESS`)를 자간 넓게 배치하는 패턴이 반복된다.
- 본문 행간이 넓어 문서가 아니라 **읽는 페이지**처럼 느껴진다.

---

## 3. Layout

- 컨테이너 최대폭 **1200px**, 좌우 여백 24px
- 12컬럼 그리드, 거터 24px
- 섹션 상하 여백 **96px** — 여백이 이 사이트의 정체성
- 카드 그리드는 3열 기본, 모바일 1열

---

## 4. Components

### Button
- Primary: 배경 `#1428A0`, 글자 흰색, 모서리 `4px`(거의 각짐), 높이 48px
- Secondary: 테두리 1px `#1428A0`, 배경 투명
- 화살표 `→`를 오른쪽에 붙이는 패턴

### Card
- 흰 배경, 테두리 `1px #DFE4EE`, 모서리 `8px`
- hover 시 그림자 `0 8px 24px rgba(11,31,58,.10)` + 1px 상승

### KPI / Stat
- 숫자 40px 700, 단위는 20px 500으로 작게
- 라벨은 숫자 아래 13px `--muted`

### Table
- 헤더 배경 `#F4F6FA`, 글자 `#16233F` 600
- 행 구분선만 있고 세로선 없음

---

## 5. Motion

- 스크롤 진입 시 `translateY(16px) → 0`, `opacity 0 → 1`, 0.5s ease-out
- hover 트랜지션 0.2s
- 과한 애니메이션 없음 — 절제된 움직임

---

## 6. 이 디자인을 내 자료에 쓸 때

**적합**: 경영층 보고, 대외 제안서, 프로젝트 현황판
**부적합**: 캐주얼한 사내 공지, 아이디어 브레인스토밍 자료

**적용 프롬프트 예시**
```
첨부한 DESIGN.md 규칙(남색 #0B1F3A, 파랑 #1428A0, 넓은 여백, 각진 버튼)을
그대로 지켜서 아래 내용을 16:9 보고용 PPT로 만들어줘.
```

## 7. 주의 — 저작권과 상표

- **색·간격·타이포 같은 디자인 원리**는 참고해도 좋다.
- **로고·상표·사진·아이콘 원본 파일**은 가져오면 안 된다.
- 경쟁사 사이트를 그대로 베낀 자료를 **대외 배포하지 않는다.**
- 사내 자료는 반드시 **회사 승인 로고**를 사용한다.
