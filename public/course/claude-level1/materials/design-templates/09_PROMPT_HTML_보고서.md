# PROMPT — HTML 보고서 만들기 (붙여넣기용)

> PPT와 **같은 재료(DESIGN.md + 스토리보드.md)** 로 HTML 보고서를 만듭니다.
> 브라우저로 바로 열리고, 메일·메신저로 링크처럼 전달할 수 있으며,
> 표 정렬·필터 같은 **움직이는 기능**을 넣을 수 있는 것이 PPT와의 차이입니다.

---

## A. 기본형 — 한 장짜리 HTML 보고서

```
첨부한 두 파일로 HTML 보고서를 만들어줘.

[디자인]
- DESIGN.md의 색·타이포·간격·컴포넌트 규칙을 그대로 지킬 것
- CSS는 DESIGN.md의 값을 :root 변수로 선언해서 쓸 것

[내용]
- 스토리보드.md의 내용만 사용. 없는 숫자 생성 금지, 불확실하면 [확인 필요]

[구조]
- 파일 1개(.html)로 완결 — CSS·JS 모두 내부에 넣고 외부 링크 금지
- 상단: 보고 제목 + 기준일 + 작성부서 + 인쇄 버튼
- KPI 카드 4개 (숫자 + 전기 대비)
- 본문 섹션: 표 + 차트 + 이슈 카드
- 하단: 데이터 출처, [확인 필요] 목록

[기능]
- 표는 열 제목 클릭으로 정렬
- 상태(정상/주의/지연) 필터 버튼
- 인쇄 시 A4 세로로 깔끔하게 나오도록 @media print 포함

[금지]
- 외부 CDN·폰트·이미지 링크 (사내망에서 안 열림)
- 근거 없는 수치 생성
```

---

## B. 대시보드형으로 만들 때

```
위 보고서를 한 화면에서 전체가 보이는 대시보드 형태로 바꿔줘.
- 상단 KPI 4개, 좌측 추이 차트, 우측 이슈 목록, 하단 상세 표
- 스크롤 없이 1920x1080에서 한 눈에 들어오게
- 차트는 외부 라이브러리 없이 순수 SVG로 그릴 것
```

---

## C. PPT와 나란히 만들 때 (권장 실습 흐름)

```
같은 DESIGN.md와 같은 스토리보드.md로
① 보고용 16:9 PPT
② 브라우저로 여는 HTML 보고서
두 가지를 만들어줘. 숫자와 결론 문장은 두 산출물이 완전히 동일해야 해.
마지막에 두 산출물의 수치가 일치하는지 대조표를 보여줘.
```

---

## D. 수정 요청 3종

```
1) 인쇄하면 표가 두 장으로 잘려. 인쇄 시 표가 안 잘리게 고쳐줘.
2) 사내망에서 폰트가 안 보여. 외부 폰트 링크 빼고 시스템 폰트로 바꿔줘.
3) 차트 색이 DESIGN.md 팔레트를 벗어났어. 지정된 색만 쓰도록 고쳐줘.
```

---

## E. HTML 보고서 체크리스트

- [ ] 파일 하나만으로 열리는가 (외부 링크 0개)
- [ ] 인터넷 없이 열어도 글꼴·색이 정상인가
- [ ] 인쇄(Ctrl+P) 했을 때 표·차트가 잘리지 않는가
- [ ] 숫자가 PPT판과 100% 일치하는가
- [ ] 데이터 출처와 [확인 필요]가 하단에 있는가
- [ ] 사외 반출 자료라면 보안 검토를 거쳤는가

## F. 언제 HTML이 PPT보다 나은가

| 상황 | 추천 |
|---|---|
| 대면 보고·회의 발표 | PPT |
| 인쇄해서 결재판에 올림 | PPT |
| 표가 30행 이상 · 정렬/필터가 필요 | **HTML** |
| 매주 같은 양식으로 갱신해 공유 | **HTML** |
| 여러 부서가 링크로 돌려봄 | **HTML** |
| 차트를 눌러 세부를 보고 싶음 | **HTML** |
