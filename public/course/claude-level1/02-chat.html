✏️ 바로 쓰는 재질문 — 내용 다듬기
너무 길어. 핵심만 5줄로 줄여줘.⧉

🗂 바로 쓰는 재질문 — 형식 바꾸기
같은 내용을 표로 다시 정리해줘.⧉
이 내용을 부서장께 보낼 업무 메일로 바꿔줘.⧉
작업 절차만 뽑아 체크리스트로 바꿔줘.⧉

💡 내용을 다시 만들지 말고 형식만 바꾸라고 하면 수치가 흔들리지 않습니다
🎯 재질문 3원칙
1
한 번에 하나만 고친다
"짧게 + 표로 + 존댓말로" 한꺼번에 시키면 결과가 무너진다
2
다시 만들지 말고 고치라고 한다
"다시 써줘"보다 "이 부분만 바꿔줘"가 수치를 지킨다
3
무엇이 아쉬운지 말한다
"별로야" ✕ → "근거가 없어서 못 쓰겠어" ○
🪞 메타프롬프팅 — 세 번 고쳐도 아쉬우면 "위 프롬프트를 좀 더 개선해줘" · 원인이 내 지시문일 수 있습니다
📎기존 결과를 첨부하면 원하는 결과로 유도하기 쉽습니다
형식을 말로 설명하는 것보다 지난주 보고서 파일 하나를 붙이는 편이 빠릅니다 — AI가 제목 구성·표 열·문체를 그대로 본떠 옵니다.
📎 지난주_주간보고.md 첨부 + "첨부한 지난주 보고서와 같은 형식으로 이번 주 것을 만들어줘. 표의 열 구성과 문체는 그대로 두고 숫자만 이번 주 자료로 바꿔줘."
❌ 말로 설명
"표는 협력사·공종·계약·누계·달성률 순으로, 제목은 굵게, 문체는 개조식으로…"
매번 다시 설명 · 빠뜨리는 항목 발생
