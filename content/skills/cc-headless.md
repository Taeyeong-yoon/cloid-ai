**사람이 앉아 있지 않은 곳에서 Claude Code를 돌리는 방법입니다.**

## 왜 알아야 하나

대화형 모드는 사람이 보고 있다는 전제 위에 있습니다. CI 파이프라인이나 크론 작업에는 맞지 않습니다.

헤드리스 모드는 입력을 받아 결과를 출력하고 끝냅니다. 파이프로 잇거나 다른 스크립트에 넣기 좋습니다.

## 개념 잡기

대화형과 결정적으로 다른 점이 있습니다.

- **중간에 물어볼 수 없습니다.** 승인 대기가 걸리면 그냥 멈춥니다 → 권한 설정을 미리 맞춰야 합니다.
- **인증 방식이 다릅니다.** 브라우저 로그인이 불가능하므로 장기 토큰이나 API 키를 씁니다.
- **출력이 곧 결과**입니다. 후속 처리가 파싱하기 쉬운 형태로 요청하세요.

CI에서 쓸 때는 이 셋을 먼저 맞춰야 실행이 됩니다.

## 바로 해보기

1. 간단한 작업을 헤드리스로 실행해 출력 형태를 확인합니다.
2. 권한 때문에 멈추는지 확인하고, 필요한 도구만 미리 허용합니다.
3. 출력을 다른 명령으로 파이프해 후속 처리가 가능한지 확인합니다.

## 흔한 실수

- **❌ 대화형과 같은 권한 설정으로 CI에서 돌린다** — 승인 대기가 걸리면 파이프라인이 그대로 멈춥니다. 사전에 허용 범위를 정하세요.
- **❌ 브라우저 로그인 방식을 CI에서 그대로 쓰려 한다** — 장기 토큰이나 API 키를 환경변수로 넘기는 방식이 필요합니다.

## 스스로 점검하기

**Q1. 헤드리스 실행이 CI에서 멈추는 가장 흔한 원인은?**

정답: 승인 대기입니다. 사람이 없으니 응답할 수 없어 그대로 멈춥니다.
